## Critical Vulnerabilities & Advisories

### Fastjson 1.x unauthenticated RCE (CVE-2026-16723) — no patch, actively exploited
**Source:** [SecurityWeek (Tier 2)](https://www.securityweek.com/unpatched-fastjson-vulnerability-exploited-in-attacks/) · **Published:** July 28, 2026 (confirmed via dedicated date search — reported "1 day ago" relative to July 29) · **CVE:** CVE-2026-16723 · **CVSS:** 9

A critical, unauthenticated remote code execution flaw in Fastjson 1.2.68–1.2.83 (unsupported branch; 2.x unaffected) is being actively exploited, primarily against Spring Boot fat-jar deployments. Imperva reported attacks hitting organizations in the US, Singapore, and Canada, with roughly 30% of observed traffic originating from tools written in Ruby and Go. As of July 25, Alibaba had not released a patched 1.x version.

### Apple patches ~194 vulnerabilities across iOS, iPadOS, macOS Tahoe, Safari

Apple's iOS/iPadOS 26.6 update fixes 87 vulnerabilities and macOS Tahoe 26.6 fixes 155, covering issues that could expose sensitive user data, allow arbitrary code execution, bypass security checks, or cause denial of service. **Source:** [BleepingComputer (Tier 1)](https://www.bleepingcomputer.com/news/security/over-24-000-exposed-server-bmcs-leak-password-hash-via-decades-old-flaw/) · **Published:** July 28, 2026 (also independently covered by [Dark Reading (Tier 2)](https://www.darkreading.com/cyber-risk/flaw-exposes-data-centers-server-takeover), same date)

## Threat Intelligence & Research

### AutoIT-based payload injector used in fake-bank-email malware campaign
**Source:** [SANS ISC Handler's Diary (Tier 1)](https://isc.sans.edu/diary/AutoIT%20Payload%20Injector%20/33192) · **Published:** July 28, 2026 (confirmed — diary entry explicitly dated "Tue, Jul 28th")

A SANS ISC handler documented a wave of phishing emails (posing as bank notifications, delivering a RAR archive named "Bank_account_details.rar") that use an AutoIT3 interpreter script to decode XOR-obfuscated shellcode, launch `charmap.exe`, and inject a payload via API calls. The payload delivers VIPKeylogger, which communicates with `cphost17[.]qhoster[.]net`.

## Open Source & Supply Chain

### Gitea RCE via malicious Git hook (CVE-2026-60004, CVSS 9.8)
**Source:** [The Hacker News (Tier 2)](https://thehackernews.com/2026/07/new-gitea-rce-lets-repository-writers.html) · **Published:** July 28, 2026 (confirmed via dedicated date search)

A vulnerability in Gitea lets any user with repository-write access plant a malicious Git hook to achieve remote code execution on the server. The flaw is rated critical (CVSS 9.8); exploitation requires write access to a repository rather than being pre-authentication.

### GitHub adds automatic malware scanning at npm publish time
**Source:** [GitHub Changelog (Tier 1, GitHub Security Lab category)](https://github.blog/changelog/2026-07-28-npm-publish-time-malware-scanning-and-dual-use-metadata/) · **Published:** July 28, 2026

GitHub announced that newly published npm packages are now automatically scanned at publish time as part of its ongoing supply-chain security work; depending on scan results, a package may publish normally, be held for manual review, or be blocked outright.

### goshs (Go HTTP file server) — two new advisories, including an incomplete-fix follow-up
**Source:** [GitHub Advisory Database (Tier 2)](https://github.com/advisories/GHSA-4xpc-pv4p-pm3w) · **Published:** July 28, 2026

Two advisories were published for the `goshs` project: CVE-2026-62325, a critical SFTP authentication bypass via empty password described as an incomplete fix of an earlier CVE, and CVE-2026-54719, a high-severity ACL authorization bypass on the bulk zip-download route allowing unauthenticated reads.
